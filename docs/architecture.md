# rv32i_core アーキテクチャドキュメント

## 概要

`rtl/rv32i_core.sv` に実装されたシングルモジュール構成の RV32I プロセッサコアです。
RISC-V 基本整数命令セット（32ビット）を多サイクル方式で実装しており、合成可能かつ読みやすさを優先した設計になっています。

---

## モジュール構成

本コアは `rv32i_core` という単一のモジュールで構成されています。
サブモジュールへの分割は行われておらず、すべての機能が一つの `.sv` ファイルに記述されています。

```
rv32i_core
├── パラメータ
├── ポート定義
├── ローカルパラメータ（オペコード定数）
├── ステートマシン定義（state_t 列挙型）
├── 内部レジスタ（_q サフィックス）
├── 組み合わせ論理信号（_d サフィックス）
├── ヘルパー関数
│   ├── make_byte_word()
│   └── make_half_word()
├── always_comb ブロック①：命令デコード・ALU演算
├── always_comb ブロック②：外部ポート出力生成
└── always_ff ブロック：ステートマシン・レジスタ更新
```

## ポート定義

| ポート名      | 方向   | 幅     | 説明                                               |
|-------------|--------|--------|---------------------------------------------------|
| `clk`        | input  | 1      | クロック（立ち上がりエッジで動作）                   |
| `rst_n`      | input  | 1      | 非同期リセット（アクティブ Low）                     |
| `imem_addr`  | output | 32     | 命令メモリアドレス（現在の PC 値）                   |
| `imem_rdata` | input  | 32     | 命令メモリ読み出しデータ（同サイクル応答前提）         |
| `dmem_valid` | output | 1      | データメモリアクセス有効フラグ                       |
| `dmem_addr`  | output | 32     | データメモリアドレス                                |
| `dmem_wdata` | output | 32     | データメモリ書き込みデータ                           |
| `dmem_wstrb` | output | 4      | データメモリ書き込みストローブ（バイトイネーブル）     |
| `dmem_rdata` | input  | 32     | データメモリ読み出しデータ（同サイクル応答前提）       |
| `trap`       | output | 1      | 例外・不正命令検出フラグ（High で停止状態を示す）     |

## ステートマシン

6 ステートの FSM（有限状態機械）で命令実行の各フェーズを管理します。

```
                ┌─────────────────────────────────────────────────────────────────┐
                │                                                                 │
         ┌──────▼──────┐                                                         │
  rst_n  │   FETCH     │  PC アライン違反                                         │
 ──────► │             ├──────────────────────────────────────────────────────► TRAP
         └──────┬──────┘                                                         ▲
                │ imem_rdata 取り込み                                             │
         ┌──────▼──────┐                                                         │
         │   DECODE    │                                                         │
         │             │                                                         │
         └──────┬──────┘                                                         │
                │ 組み合わせ論理でフィールド解析済み                                │
         ┌──────▼──────┐  exec_illegal / branch_misaligned                      │
         │   EXECUTE   ├────────────────────────────────────────────────────────►│
         │             │                                                         │
         └──┬──┬──┬────┘                                                         │
            │  │  │                                                              │
            │  │  │ BRANCH（not taken）  ┌─ FETCH ◄────────────────────────────┘
            │  │  └─────────────────────►│             ▲ STORE 完了
            │  │                         │             │
            │  │ FENCE（NOP）            └─────────────┘
            │  └────────────────────────────────────────────────────────────────►│
            │                                                                    │ FETCH
            │ LOAD/STORE（アライン OK）                                           │
     ┌──────▼──────┐  mem_illegal                                               │
     │   MEMORY   ├────────────────────────────────────────────────────────────►│ TRAP
     │             │                                                             │
     └──────┬──────┘                                                             │
            │ LOAD 完了                                                          │
     ┌──────▼──────┐                                                             │
     │  WRITEBACK  │                                                             │
     │             │ regs_q 更新 → FETCH                                        │
     └─────────────┘
```

### ステート遷移まとめ

| 現在のステート | 遷移先           | 遷移条件                                              |
|-------------|-----------------|------------------------------------------------------|
| `FETCH`     | `DECODE`        | PC アライン OK（`pc_q[1:0] == 2'b00`）                |
| `FETCH`     | `TRAP`          | PC アライン違反                                       |
| `DECODE`    | `EXECUTE`       | 常に                                                 |
| `EXECUTE`   | `WRITEBACK`     | LUI/AUIPC/OP/OPIMM/JAL/JALR                          |
| `EXECUTE`   | `FETCH`         | BRANCH（taken/not-taken とも）、FENCE                 |
| `EXECUTE`   | `MEMORY`        | LOAD/STORE（アライン OK）                             |
| `EXECUTE`   | `TRAP`          | 不正命令、ミスアライン分岐、SYSTEM 命令               |
| `MEMORY`    | `WRITEBACK`     | LOAD 完了                                            |
| `MEMORY`    | `FETCH`         | STORE 完了                                           |
| `MEMORY`    | `TRAP`          | アライメントエラー                                    |
| `WRITEBACK` | `FETCH`         | 常に（レジスタ書き込み後）                             |
| `TRAP`      | `TRAP`          | 常に（以降この状態に留まる）                           |

|-------------|----------------|----------------------------------------------|

| `wb_data_q` | `[31:0]`       | ライトバックデータ                              |

## ヘルパー関数

### `make_byte_word(data_byte, byte_offset)`

8 ビットデータを 32 ビットワード内の指定バイト位置に配置する。

| 引数          | 幅      | 説明                                         |
|-------------|---------|----------------------------------------------|
| `data_byte` | `[7:0]` | 配置するバイトデータ                           |
| `byte_offset` | `[1:0]` | 配置先バイト位置（0〜3）                      |

`byte_offset = 0` のとき `[7:0]`、`1` のとき `[15:8]`、`2` のとき `[23:16]`、`3` のとき `[31:24]` に配置。

### `make_half_word(data_half, upper_half)`

16 ビットデータを 32 ビットワードの上位または下位半分に配置する。

| 引数          | 幅       | 説明                                             |
|-------------|----------|--------------------------------------------------|
| `data_half` | `[15:0]` | 配置するハーフワードデータ                         |
| `upper_half` | `1`     | 0: `[15:0]` に配置、1: `[31:16]` に配置           |

| 命令     | 動作                            |

## 例外・トラップ

以下の条件で `STATE_TRAP` に遷移し、`trap` 出力が High になります。一度遷移すると復帰しません。

| 原因                                  | 検出ステート    |
|---------------------------------------|--------------|
| PC のアライメント違反（`pc_q[1:0] != 0`） | FETCH       |
| 未定義オペコード                        | EXECUTE     |
| 不正な `funct3` / `funct7` の組み合わせ  | EXECUTE     |
| 分岐先アドレスのアライメント違反          | EXECUTE     |
| SYSTEM 命令（ECALL/EBREAK 等）          | EXECUTE     |
| ロード/ストアのアライメント違反          | EXECUTE/MEMORY |

## タイミング前提

- 命令メモリ：`imem_addr` に対する命令が**同サイクル**に `imem_rdata` で得られる（非同期 ROM 相当）
- データメモリ：`dmem_addr` / `dmem_wstrb` に対するアクセスが**同サイクル**に完了する（待ちなし前提）
